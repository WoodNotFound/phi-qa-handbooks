标签页关闭操作
完整手测指南

从两个设置开关开始，逐项核对普通标签、分屏、固定项、标签组和书签。每项写明初始状态、操作和剩余集合；三种布局、语言和关键输入变体分别记录结果。

本页是测试规范，不是全量通过报告。所有本轮结果初始为“未测”。“历史实测”只表示对应布局曾有开发自测记录，不自动替你判通过。

参考结构：关注页面与任务汇报手测。本功能主要是原生 macOS 行为，基础用例无需启动 phi-agent、数据库、Sidecar 开发服务或使用 AI。

开测前准备

  1. 先拿到正确构建。被测分支为 feature/tab-close-improvements。本手册对应的功能目前仍是本地未提交修改，不能仅靠获取分支名或 checkout 基线提交就假定包含完整功能。由发包人提供 app 或合入后的准确提交。
  2. 记录实际 app 路径／渠道、构建标识、macOS 和 Framework。开发自测使用 OpenSource 本地构建，Framework 为 156.0.8078.52 / 8078.52；这只是已用版本，不是所有版本兼容承诺。
  3. 建立 TC-QA 临时 Space，页面全部使用下方 fixture。pin 可能跨 Space 共用，不要直接清空 pin 区；只动带 TC- 前缀且本轮新建的测试项。
  4. 记录原布局、两个开关与快捷键。每条用例先重建初始序列，等原生列表和标题稳定再操作；不要把上一条关闭后的残留当作新基线。
  5. 标记“未保存型”的 fixture 只有在输入后才拦截离开。看到“离开确认已启用”再测。用 pin／书签输入标记和打开编号，区分“保存项还在”和“实时页面没被关”。

测试页面生成器

只生成普通静态网址，不替你创建标签组／分屏，也不会自动关闭任何页面。普通页带临时输入框；离开确认型页面只在输入后注册确认。

按 A → F 顺序逐个打开后，核对实际列表；如被浏览器插到别处，手动拖回基线。不要认为最后打开的一定排最后。

打开自定义页面

初始序列记法：A | S[B+C] | D 表示普通 A、一个 B/C 合并分屏项、普通 D。G[B,C,D] 表示标签组成员；P 表示测试 pin；M 表示保存书签。页面内部的左右／上下分屏不决定标签栏方向。

关闭规则速查

对象方向关闭 / 关闭其他单页或显式操作
普通 tab当前窗口、当前 Space；按真实可见顺序计算，右键页为锚点双击是否关闭由独立开关控制
普通 split锚点保留两边；目标关闭两边双击某半格只关该页；另一页转为单页
Pin / pinned split整体保护；自己的菜单没有方向项已有显式关闭只关实时页面，保存项仍在
组内 tab可以跨组计算；仅关闭落入范围的成员组名、颜色及剩余成员保留
组标题 / 折叠组整组是保留边界；折叠不改变成员参与范围最后成员关闭沿用现有组确认；没有“自动保存空组”的新承诺
纵向书签区绑定页页面和保存项都保护；split bookmark 两页保护保存项不作为普通列表方向锚点
水平栏中的书签打开页作为普通页参与；目标 split 整对关闭关闭页面不删除保存的书签或文件夹

两个开关：“双击关闭标签页”默认关；“按位置批量关闭标签页”默认开。后者关闭时，隐藏普通及组方向项，方向快捷键不执行；已有“关闭其他标签页”仍可用。两个开关对同一 app 的窗口／Space 生效，不是每个标签单独设置。

取消不等于全批回滚。网页 beforeunload 或组确认可能让部分目标保留，而其他目标已经关闭。判定每个页面的实际结果。永久删除组仅用明确可丢弃的 TC-G，由测试人核对后确认，不勾选“不再询问”。

复杂对象搭建与重置

每项公共前置：除用例明确要求关闭／首次默认／升级测试外，双击关闭与位置关闭都设为开；切到本执行点布局，使用本轮 TC- 对象，先写出初始集合，再重建基线。标为“按原有规则”的生命周期和集成回归，需要用同环境已有关闭按钮／旧构建先记录对照；没有可比基线时说明并标阻塞，不能凭印象通过。

先用本轮唯一 run 标识逐页打开 fixture，再用原生拖动排顺序。以下操作只针对本轮 TC- 对象；同一个字母可以代表不同文档，必须用打开编号区分。

对象手动搭建开测前核对 / 重置
普通分屏 S[B+C]先激活 B，再在未分屏 C 的原生菜单选择“与当前标签页分屏 / Split with Current”；也可用已有 Option-单击入口。确认 B/C 合并为同一项；两页各输入标记。通过现有分屏菜单调整内部左右／上下、交换两侧和比例；重建用原生取消分屏或新开两个 fixture。
组 TC-G[B,C,D]右键 B → 新建标签组 / New Tab Group，命名 TC-G；通过成员菜单加入同一组，或把 C/D 拖入。确认组展开时列出全部成员。设置非默认颜色；折叠时记录隐藏成员清单。关闭组可能触发永久删除确认，只用可丢弃测试组，不勾“不再询问”。
组内分屏先建普通组，再把两个成员通过原有分屏入口配对；或将普通 split 移入组。以 UI 支持的入口为准。组标题、成员行和两个半格是不同点击目标。菜单缺失或 UI 禁止某结构时记录具体限制，不修改数据库制造结构。
Pin / 固定 split在普通页或普通 split 的原生菜单选固定。分别准备已打开、已显式关闭但仍保存的测试项。固定区不按普通方向排序。每次核对保存项和实时标记；收尾只取消本轮新增固定项。
书签 / split 书签普通页菜单保存书签；split 菜单使用“添加分屏到书签”而非只保存一侧。放入 TC- 专用文件夹，按需再嵌套一层。纵向从书签区打开形成绑定页；水平打开通常进入普通栏。以实时 UI 身份确认资格，不凭 URL 是否收藏推断。关闭实时内容与删除保存记录是不同动作。
多选与快捷键单击第一个普通项，Command-单击另一个；Shift 用于连续范围。关闭其他从选中集合菜单执行。旧关闭右侧／关闭其他的测试绑定在设置的快捷键页配置。执行前截图实际选中单位。测试绑定必须无冲突，结束恢复；旧“关闭右侧”在纵向表示原生顺序的后方。
未保存、媒体、下载与辅助页未保存 fixture 必须真实输入后看到已启用提示。音频可使用下方 fixture 的手动播放按钮；下载可使用其可丢弃文本文件。Reader／Peek／Sidecar 通过已有 UI 打开。输入和音频不会自动启动；不使用真实会议或重要下载。缺少官方功能、权限或测试硬件时记阻塞并说明前置，不代用内部脚本。

覆盖矩阵与验收标准

本版根据当前 Mac 实现的入口、资格过滤、原生顺序、split 扩展和关闭生命周期重新审查。下面将每个测试维度映射到具体编号；“完整”指本批功能范围的验收矩阵，不代表穷举所有系统、输入时序或第三方网页。

维度明确覆盖的边界对应用例
P0：核心关闭正确性与数据保护，适用环境全部必测。P1：发布完整回归，也需执行；失败必须修复或由发布负责人明确接受，不能因为不是 P0 就忽略。P2：条件集成与探索，必须逐项说明已测／阻塞／不适用。跳过不是通过。

结果类型：“验收／回归”有具体剩余集合或不变量；“探索／待定标准”只能记录观察，产品标准未确认时记阻塞。分屏／组完整元数据恢复、跨目标的快速点击和模态交错没有凭空许诺的固定行为。所有取消路径都要检查被取消文档存活，但不要求整批原子回滚。

完成条件：已声明发布的每个环境都跑过适用 P0/P1；9 种语言在 3 个布局各有结果；P2 缺失前置逐项说明；无未处理的数据丢失、误关、崩溃或所有权隔离问题；失败／阻塞／跳过有理由、负责人或处置；报告记录准确构建与本轮编号。冒烟通过只说明可以开始回归。

不具备手册网页交互环境时，可查看或保存完整静态 Markdown 手册（含全部步骤与预期）。页面筛选不会减少导出报告范围。

报告与收尾

  1. 所有本轮适用 P0 必须通过；P1 完整回归执行完毕且无未处理失败。P2 逐项说明覆盖／缺失，探索标准未决时标阻塞。失败、阻塞、跳过、未测均不能计为通过；不具备官方功能环境的扩展项说明前置条件缺失。
  2. 失败至少记录：用例 ID、布局、构建、两个开关值、初始顺序、活动页、右键对象、操作、预期／实际剩余集合、对话框选择及截图。崩溃另附发生时间和系统崩溃记录，先去除私人网址和账号。
  3. 导出 JSON 备份和 Markdown。导出包含全部记录，不随当前筛选隐藏失败；无备注的失败／阻塞会在报告中提示补全。
  4. 恢复布局、开关及快捷键；只取消测试新增 pin。逐一核对后清理临时组／书签／窗口。不要删除真实组，不要清空整个浏览数据。
