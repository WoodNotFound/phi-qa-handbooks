标签页关闭操作
完整手测指南

从两个设置开关开始，逐项核对普通标签、分屏、固定项、标签组和书签。每项写明初始状态、操作和剩余集合；三种布局分别记录结果。

本页是测试规范，不是全量通过报告。所有本轮结果初始为“未测”。“历史实测”只表示对应布局曾有开发自测记录，不自动替你判通过。

参考结构：关注页面与任务汇报手测。本功能主要是原生 macOS 行为，基础用例无需启动 phi-agent、数据库、Sidecar 开发服务或使用 AI。

开测前准备

  1. 先拿到正确构建。被测分支为 feature/tab-close-improvements。本手册对应的功能目前仍是本地未提交修改，不能仅靠获取分支名或 checkout 基线提交就假定包含完整功能。由发包人提供 app 或合入后的准确提交。
  2. 记录实际 app 路径／渠道、构建标识、macOS 和 Framework。开发自测使用 OpenSource 本地构建，Framework 为 156.0.8078.52 / 8078.52；这只是已用版本，不是所有版本兼容承诺。
  3. 建立 TC-QA 临时 Space，页面全部使用下方 fixture。pin 可能跨 Space 共用，不要直接清空 pin 区；只动带 TC- 前缀且本轮新建的测试项。
  4. 记录原布局、两个开关与快捷键。每条用例先重建初始序列，等原生列表和标题稳定再操作；不要把上一条关闭后的残留当作新基线。
  5. 标记“未保存型”的 fixture 只有在输入后才拦截离开。看到“离开确认已启用”再测。用 pin／书签输入标记和打开编号，区分“保存项还在”和“实时页面没被关”。

以浏览器仓库的 docs/open-source-build.md 为准，先取得包含完整修改的工作区及匹配 Framework。下面只构建 app，不运行内置测试。首次开发环境所需依赖不由这条命令自动包办。

xcodebuild -project Phi.xcodeproj \
  -scheme PhiBrowser-OpenSource \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath build/DerivedData-TabCloseQA \
  CODE_SIGNING_ALLOWED=NO build

产物为 build/DerivedData-TabCloseQA/Build/Products/OpenSource/Phi.app。明确打开该路径，避免启动了正式版或 Canary。OpenSource 不支持 AI 的扩展用例应记“阻塞”，不要为了通过修改内部状态。

建议分轮：冒烟集约 30–60 分钟；完整矩阵按布局分给测试人，约 4–6 小时，加上其他语言、隐身和 agent 环境准备。用时是估计，不是实测工时。

测试页面生成器

只生成普通静态网址，不替你创建标签组／分屏，也不会自动关闭任何页面。普通页带临时输入框；离开确认型页面只在输入后注册确认。

按 A → F 顺序逐个打开后，核对实际列表；如被浏览器插到别处，手动拖回基线。不要认为最后打开的一定排最后。

打开自定义页面

初始序列记法：A | S[B+C] | D 表示普通 A、一个 B/C 合并分屏项、普通 D。G[B,C,D] 表示标签组成员；P 表示测试 pin；M 表示保存书签。页面内部的左右／上下分屏不决定标签栏方向。

关闭规则速查

对象方向关闭 / 关闭其他单页或显式操作
普通 tab当前窗口、当前 Space；按真实可见顺序计算，右键页为锚点双击是否关闭由独立开关控制
普通 split锚点保留两边；目标关闭两边双击某半格只关该页；另一页转为单页
Pin / pinned split整体保护；自己的菜单没有方向项已有显式关闭只关实时页面，保存项仍在
组内 tab可以跨组计算；仅关闭落入范围的成员组名、颜色及剩余成员保留
组标题 / 折叠组整组是保留边界；折叠不改变成员参与范围最后成员关闭沿用现有组确认；没有“自动保存空组”的新承诺
纵向书签区绑定页页面和保存项都保护；split bookmark 两页保护保存项不作为普通列表方向锚点
水平栏中的书签打开页作为普通页参与；目标 split 整对关闭关闭页面不删除保存的书签或文件夹

两个开关：“双击关闭标签页”默认关；“按位置批量关闭标签页”默认开。后者关闭时，隐藏普通及组方向项，方向快捷键不执行；已有“关闭其他标签页”仍可用。两个开关对同一 app 的窗口／Space 生效，不是每个标签单独设置。

取消不等于全批回滚。网页 beforeunload 或组确认可能让部分目标保留，而其他目标已经关闭。判定每个页面的实际结果。永久删除组仅用明确可丢弃的 TC-G，由测试人核对后确认，不勾选“不再询问”。

报告与收尾
